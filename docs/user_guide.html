1. Назначение

Приложение автоматически преобразует документы Word (DOCX/DOC) в модули данных стандарта S1000D в формате XML. Процесс состоит из двух этапов:

1
Кодирование структуры Папка с исходными документами Word преобразуется в двухуровневую структуру папок S1000D. Каждая папка — один модуль данных с присвоенным кодом DMC.
2
Генерация XML Документы Word разбираются на структурные элементы (заголовки, параграфы, таблицы, иллюстрации, предупреждения) и преобразуются в XML-модули данных S1000D, валидные по XSD-схеме.

Результат можно просматривать в двухпанельном интерфейсе сравнения (исходный документ слева, XML справа) для контроля точности.

2. Запуск приложения

1
Запустите word_to_s1000d.exe Откроется окно терминала с адресом сервера (по умолчанию http://127.0.0.1:5000).
2
Откройте браузер Перейдите по адресу http://127.0.0.1:5000. Откроется главная страница приложения.
Требования: На компьютере должен быть установлен Microsoft Word (для конвертации старых файлов формата .doc в .docx). Для работы с файлами .docx Microsoft Word не требуется.

Интерфейс главной страницы

Главная страница содержит:

  • Панель путей — текущие папки: исходные документы, структура S1000D, выходные XML
  • Статистика исходных документов — количество найденных файлов по типам
  • Полоса прогресса — статус конвейера (кодирование, DOCX, XML, проверка)
  • Кнопки генерации:
    • Сгенерировать структуру — только кодирование папок
    • Генерировать XML — только XML из уже закодированных модулей
    • Генерировать все — структура + XML последовательно
  • Таблица модулей данных — список всех модулей с DMC-кодами и статусами

3. Подготовка исходных документов

Поместите исходные документы Word в папку (например, doc_source_29_raw). Инструмент автоматически определяет организацию папки и работает с двумя вариантами:

Вариант А — по типам документов

Документы разложены по подпапкам:

doc_source_29_raw/ 029.00.00 Описание/ 029.11.01 описание гидрокомпенсатор.doc 029.11.02 описание гидроаккумулятор.doc ... 029.00.00 Технология/ 029.11.01 ТК 1 демонтаж.doc 029.11.01 ТК 2 осмотр.doc ... 029.00.00 Рисунки описание/ 029.11.01 рисунок 1 общий вид.cdr ...

Вариант Б — по компонентам

Каждый компонент в отдельной папке (по коду: система.подсистема.компонент):

doc_source_12_raw/ 012.00.00/ 012-00-00.doc 012-00-00 Таблица 1.doc 012-02-00.doc ... 012.91.00/ 012.91.00 ТК 1.doc 012.91.00 ТК 2.doc ...

Правила именования файлов

Тип документаФормат имени файлаПример
ОписаниеКод + описание029.11.01 описание гидрокомпенсатор.doc
Описание (краткое)Только код012-00-00.doc
Технологическая картаКод + ТК + номер029.11.01 ТК 1 демонтаж.doc
ТаблицаКод + Таблица + номер012-00-00 Таблица 1.doc
РисунокКод + рисунок + номер029.11.01 рисунок 1.cdr
Подсказка: Код компонента может быть записан через точку или дефис: 029.11.01 и 029-11-01 — эквивалентны.

Временные файлы игнорируются автоматически: ~$..., ~WRL..., Thumbs.db, desktop.ini, *.tmp.

4. Генерация структуры S1000D

На этом этапе папка с исходными документами преобразуется в структуру с DMC-кодами.

1
Укажите путь к исходным документам В настройках (кнопка ⚙) задайте поле Папка сырых документов.
2
Нажмите Сгенерировать структуру Инструмент:
  • Сканирует файлы и определяет типы документов по именам файлов
  • Извлекает заголовки из документов Word
  • Назначает каждому документу код DMC
  • Создает двухуровневую структуру папок
3
Проверьте результат После генерации страница перезагрузится и покажет список модулей данных. Отчет генерации покажет количество компонентов, модулей данных и результат извлечения названий.

Что получается на выходе

Двухуровневая структура папок:

doc_source_29_generated/ 029-00-00 - Гидравлическая система/ [S5-A-029-00-00-00A-005A-A] Перечень принятых сокращений/ [S5-A-029-00-00-00A-040A-A] Описание и принцип действия/ 029-11-01 - Гидрокомпенсатор/ [S5-A-029-11-01-00A-040A-A] Описание устройства/ [S5-A-029-11-01-00A-920A-A] Демонтаж и монтаж/

Каждая папка уровня 2 содержит DMC-код в квадратных скобках и исходный документ Word.

5. Генерация XML

Преобразование документов Word в XML-модули данных S1000D.

1
Нажмите Генерировать XML Каждый документ Word обрабатывается последовательно:
  • Конвертация .doc в .docx (если нужно)
  • Разбор документа на элементы (заголовки, параграфы, списки, таблицы, иллюстрации)
  • Определение типов элементов (предупреждения, примечания и т.д.)
  • Генерация XML в формате S1000D
  • Валидация по XSD-схеме
2
Наблюдайте за прогрессом Полоса прогресса показывает текущий модуль и общий счетчик.

После завершения в таблице модулей столбец XML покажет ✓ для успешно сгенерированных модулей.

Ошибки XSD: Если XML не проходит валидацию, статус покажет ✗. Это означает, что структура документа содержит элементы, не соответствующие схеме S1000D. Такие модули можно доработать вручную в интерфейсе сравнения.

Кнопка «Генерировать все»

Кнопка Генерировать все (структура+XML) выполняет оба этапа последовательно: сначала структуру, затем XML для всех модулей.

6. Просмотр и сравнение

Для каждого модуля данных доступен интерфейс сравнения — двухпанельное представление для контроля точности генерации.

Левая панель: исходный документ

Отображение исходного документа в виде PDF. Текстовые блоки автоматически размечены цветными маркерами для визуального соответствия с XML.

Правая панель: XML-модуль

Результат генерации XML отрисован в виде HTML с аннотациями типов элементов. Каждый элемент показывает свой тип (параграф, заголовок, таблица, иллюстрация и т.д.).

Действия в интерфейсе сравнения

  • Навигация — клик по маркеру в одной панели подсвечивает соответствующий элемент в другой
  • Перегенерация XML — кнопка для повторной генерации текущего модуля
  • Редактирование разметки — контекстное меню позволяет изменить тип элемента, объединить или разделить элементы

7. Настройки

Настройки доступны через кнопку ⚙ в правом верхнем углу страницы. Все параметры также можно задать в файле config.ini.

ПараметрОписаниеПример
Папка сырых документов Путь к исходной папке с документами Word doc_source_29_raw
Структура S1000D Путь к папке со структурой DMC-кодов (результат этапа 1) doc_source_29_generated
Выходные XML Папка для сгенерированных XML-файлов ./tg_web/suites/66935
Эталонная папка Папка с эталонной структурой для проверки результата генерации (необязательно) doc_source_29_reference
Подсказка: После изменения настроек нажмите Сохранить. Страница перезагрузится, и панель исходных документов покажет обновленную информацию.

8. Частые вопросы

Какие форматы файлов поддерживаются?

Документы: .doc, .docx. Графика: .cdr, .jpg, .png. Для конвертации .doc в .docx необходим установленный Microsoft Word.

Что делать, если заголовок модуля не определился?

Заголовок извлекается из первого содержательного абзаца документа. Если документ в формате .doc, требуется конвертация в .docx через Microsoft Word. Убедитесь, что Word установлен и не заблокирован другими процессами.

Как обновить XML после правок в Word?

Нажмите кнопку XML напротив нужного модуля в таблице на главной странице. Модуль будет перегенерирован из обновленного документа.

Можно ли обработать несколько разделов?

Да. Укажите в настройках другую папку исходных документов и нажмите Сгенерировать структуру. Инструмент поддерживает как плоскую структуру, так и вложенные папки по подсистемам.
